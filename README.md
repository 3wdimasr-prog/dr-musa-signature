# د. موسى المطيري — النسخة السينمائية

موقع عربي باتجاه RTL، ملفات ثابتة جاهزة للنشر على Vercel، دون بناء أو قاعدة بيانات.

## التشغيل والنشر

ارفع محتويات هذه الحزمة إلى مستودع مشروع Vercel، ثم استخدم Framework Preset: Other.
لا يوجد Build Command. استخدم جذر المشروع كـ Output Directory (`.` إذا طُلب حقل).
يجب أن يوجد index.html وstyle.css وapp.js وassets في الجذر نفسه.

حزمة Vercel جاهزة، ولم يُنفَّذ نشر إلى حساب Vercel. توجد معاينة خاصة مستقلة للمراجعة عبر Sites؛ ليست نشر الإنتاج على Vercel.

الملف المنفرد dr-musa-signature.html يتضمن CSS وJavaScript والصور لتسهيل فتحه ومراجعته.
الخط العربي يستخدم Google Fonts مع بديل محلي؛ لا يحتاج المحتوى إلى خدمة خارجية ليظهر.

## ما تغيّر

- افتتاحية جديدة بصورة الطبيب وهوية داكنة بألوان أخضر عميق وذهبي وعاجي.
- رحلة استشارة في مشهد ثابت أثناء التمرير، من أربع مراحل: الهدف، التقييم، الخيارات، الخطة.
- مجسّم خطي فني مرسوم بـ Canvas؛ تتقارب أجزاؤه وتتغير زاويته مع التمرير. طبقات SVG مستقلة للخطوط والعناوين.
- أزرار تتيح اختيار المرحلة مباشرة. الشاشات ذات ارتفاع 480 بكسل أو أقل تستعمل العرض العادي مع اختيار يدوي، دون تثبيت مشهد أطول من الشاشة.
- ستة مجالات ممارسة برسوم خطوط مختلفة وقائمة تدعم لوحة المفاتيح.
- السيرة والمؤهلات والمسيرة المهنية، وفرعا الكشف، وطلب موعد عبر واتساب.
- حماية من الحركة الزائدة بحسب prefers-reduced-motion، وصورة SVG بديلة إن تعذر Canvas.
- لا اعتراض لحركة العجلة أو اللمس، ولا تشغيل فيديو. الرسم مرتبط بالتمرير، أو معاينة اختيارية محددة المدة. لا توجد حلقة Canvas دائمة.

## التصميم المتجاوب

قواعد مخصصة للجوال والتابلت والكمبيوتر، مع نقاط تغيير عند 370 و700 و900 و1150 و1600 بكسل.
رحلة التمرير تتحول إلى مشهد عادي عند ارتفاع شاشة 480 بكسل أو أقل، لتفادي قص المحتوى في الشاشات القصيرة والوضع الأفقي.
شريط اتصال ثابت على الجوال يدعم safe-area، وأزرار ولوحة مفاتيح ونموذج بخطوط إدخال مناسبة.

## التحقق وحدوده

نجحت اختبارات DOM ومنطق التفاعل: روابط الأقسام والصور والأرقام، المراحل الأربع والتمرير العكسي، هندسة Canvas المحدودة، الخدمات الستة ولوحة المفاتيح، التنقل وإغلاق القائمة، الفرع، تطبيع رقم الجوال ورسالة واتساب، حالات تقليل الحركة وغياب Canvas.
نجح فحص صياغة JavaScript وCSS.
لم تتوفر المعاينة البصرية داخل متصفح في هذه البيئة؛ لم يُجر اختبار بصري على أجهزة فعلية.
لم يُرسَل طلب حجز حقيقي. لم يُختبر تأكيد الموعد لدى الجهة المستقبلة.

## المحتوى والصور

المجسّم والرسوم تصورات فنية؛ ليست قياسات أو محاكاة نتائج علاجية.
المشهد المكتبي مولّد، وموسوم بذلك في الصفحة. صورة البيئة الجراحية من مرفقات المستخدم.
المؤهلات مستندة إلى الملفات المهنية المنشورة، دون اختراع سنوات أو عدد عمليات أو آراء مرضى.
لا أسعار أو عروض. تفاصيل المصادر في SOURCES.md وتفاصيل الصور في ASSETS.md.

## ترقية الحركة

صورة الطبيب تتجمع من ثماني شرائح تتحرك بعمق ودوران، ومدارات تتحرك مع التمرير، وبطاقات للهدف والخيارات والخطة تدخل تدريجيًا. زر «شغّل المشهد» يعرض المراحل خلال 10.5 ثانية ويمكن إيقافه. التمرير أو اللمس يوقف تشغيل المعاينة ويعيد التحكم الطبيعي للزائر. افتتاحية بصورة متحركة وستائر كشف وضوء ومدارات متحركة، وتكوين للجوال يضع صورة الطبيب مع الاسم في الجزء الأول من الصفحة. رسوم المجالات ترسم خطوطها عند الاختيار.

نجحت اختبارات التجميع وتشغيل المشهد حتى النهاية وإيقافه، بالإضافة إلى استمرار الحركة بالتمرير عند ارتفاع جوال 568 بكسل. ما زالت المعاينة البصرية داخل المتصفح غير متاحة في هذه البيئة.
